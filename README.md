# AllyAdore Shopify Theme

A luxurious, custom Shopify theme designed for beauty and fragrance e-commerce stores.

## Features

- 🎨 Elegant, warm color palette (bronze, beige, gold tones)
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🛒 Complete e-commerce functionality (products, collections, cart, checkout)
- 🎁 Gift section showcase
- ⚡ Fast-loading optimized assets
- 🔧 Easy-to-customize settings

## Theme Colors

- **Primary:** #8B6F47 (Bronze)
- **Secondary:** #D4A574 (Gold)
- **Accent:** #F5E6D3 (Cream)
- **Text:** #2C2C2C (Dark)
- **Background:** #FFFFFF (White)

## Fonts

- **Headings:** Playfair Display (Serif)
- **Body:** Poppins (Sans-serif)

## Installation

1. Clone this repository
2. Connect to your Shopify store using Shopify CLI
3. Upload the theme to your Shopify admin
4. Customize settings and content in the theme editor

## Directory Structure

```
├── assets/           # CSS and JavaScript files
├── config/           # Theme configuration and settings
├── layout/           # Main theme layout file
├── sections/         # Reusable theme sections
├── templates/        # Page templates
└── theme.toml        # Theme metadata
```

## Sections

- **Header** - Navigation and logo
- **Hero** - Large banner with call-to-action
- **Featured Products** - Product grid showcase
- **Gift Section** - Special gift/promotion area
- **Footer** - Footer with links and social media

## Templates

- **index.liquid** - Homepage
- **product.liquid** - Product detail page
- **collection.liquid** - Collection/category page
- **cart.liquid** - Shopping cart page

## Customization

All theme settings can be customized through the Shopify Theme Editor, including:
- Colors and fonts
- Hero section content
- Product showcases
- Footer links
